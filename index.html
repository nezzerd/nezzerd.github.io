BookIT: платформа для бронирования отелей

Система, которая объединяет путешественников и владельцев отелей в единой экосистеме. Работайте на платформе как клиент, ищущий идеальный отель, или как отельер, управляющий своей сетью.

Для клиентов

  • Поиск отелей по расширенным фильтрам
  • Бронирование в несколько кликов
  • Управление всеми бронированиями
  • История путешествий

Для отельеров

  • Управление несколькими отелями
  • Добавление и редактирование информации
  • Статистика бронирований
  • Аналитика загрузки номеров

Основной функционал

BookIT предлагает два режима работы на одной платформе. Выберите свою роль при входе в систему

Два способа использования системы BookIT

Сценарий первый - отельерский

После выбора режима "Отельер" в главном меню вы получаете доступ к панели управления своими отелями

Управляйте своей сетью отелей, добавляйте новые объекты, отслеживайте бронирования и анализируйте статистику в панели управления.

  1. Войдите в систему под своей учетной записью отельера
  2. Выберите "Добавить отель" для создания новой гостиницы
  3. Заполните информацию: название, город, описание, фотографии, удобства
  4. Настройте номера и цены для каждого типа размещения
  5. Просматривайте статистику бронирований и загрузку номеров

Сценарий второй - клиентский

Выберите режим "Клиент" для поиска и бронирования отелей по всему миру

Находите подходящие отели с помощью расширенных фильтров и бронируйте номера в несколько кликов.

  1. Войдите в систему как клиент
  2. Укажите параметры поиска: город, даты, количество гостей
  3. Примените дополнительные фильтры: цена, удобства
  4. Просмотрите список подходящих отелей с фотографиями
  5. Выберите отель, проверьте наличие и завершите бронирование

REST API

Все пользователи

POST Создание аккаунта
/api/auth/register
Создание новой учетной записи.
POST Авторизация
/api/auth/login
Вход в систему.

Клиенты

GET Поиск отелей
/api/hotels/search
Поиск отелей по фильтрам: город, даты, количество гостей, цена, удобства.
GET Список бронирований
/api/bookings
Получение списка бронирований клиента.
POST Создание бронирования
/api/bookings
Создание нового бронирования на выбранный отель и даты.

Отельеры

GET Список отелей
/api/hotelier/hotels
Получение списка всех отелей, принадлежащих текущему отельеру.
POST Добавление отеля
/api/hotelier/hotels
Добавление нового отеля с полной информацией: название, описание, адрес, фотографии, удобства.
PUT Обновление отеля
/api/hotelier/hotels/{hotelId}
Обновление информации об отеле: изменение описания, цен, доступности номеров.
GET Бронирования отеля
/api/hotelier/bookings?hotelId={hotelId}
Получение списка всех бронирований для конкретного отеля или всех отелей отельера.
